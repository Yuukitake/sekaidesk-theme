# SekaiDesk Theme Store (`sekaidesk-theme`)

Official downloadable UI preset repository for **[SekaiDesk](https://github.com/Yuukitake/SekaiDesk)** (`v0.3.6+`).

Presets completely replace the desktop shell layout (Top Bar, Dock, Desktop Widgets, Launchers) on the fly while preserving SekaiDesk's settings hub, wallpaper manager, and native Win32 services.

## Available Presets

| ID | Name | License |
| --- | --- | --- |
| `material-you` | **Material You (End-4)** | GPL-3.0 |

## Installation

Open **SekaiDesk Settings -> `07 · PRESETS & STORE`** (or click **`🎨 PRESETS`** in the Settings Hub header), click **Download Preset**, and click **Apply Preset**.
